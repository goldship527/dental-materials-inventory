# 一般歯科材料在庫管理 デザイン基準

最終更新: 2026-10-08（UI見直し: モチーフ・配色・文字サイズ・ページ枠を全画面へ）

## 前提

- 対象: 日本語で材料を管理する現場スタッフ。ITに慣れていない人を含む。タブレットの縦・横表示を主とし、スマートフォン・PCでも操作できること。
- 目的: 商品を見つけ、何を何単位減らすのか確認し、落ち着いて確定できること。派手な装飾・小さすぎる操作・色だけの警告を避ける。
- 戦略と操作仕様は `spec.md` の出庫カード節を正本とする。
- 2026-10-08以降は本書の §1〜§5 を全画面の正とする。旧方針「既存画面全体の色・配置を一括変更しない」は、2026-10-08のUI見直しで廃止した。
- 検討の経緯: `docs/color-rationale-2026-10-08.md`（配色の根拠）、`docs/mockups/ui-revision-mockup.html`（見た目の正本。「新案4 根拠版」）。

## 1. モチーフ: ディーラーの納品書・発注伝票

色や数値を決める前に読む。AIに作らせると、コンセプトと具体値の間の空白が平均的な見た目（Tailwind既定色・青緑・淡色の塗り分け・ふんわりした影）で埋まる。その空白に、スタッフが毎回照合している実物を置く。

| 伝票の要素 | 画面での文法 |
|---|---|
| 罫線・項目名・見出し行は1色の刷り色（藍） | 構造と「押せる物」は藍。見出し行は藍の網掛け＋上罫 |
| 品名・数量は墨で記入 | データ（商品名・数量）は墨。刷り色にしない |
| 社判・訂正印は朱 | 朱は「停止」だけ（在庫0・エラー） |
| 蛍光ペンで照合した印 | 黄のマーカー面＝注意（基準未満・確認待ち） |
| 白い用紙と台紙 | 記入面（カード・表）は白、背景は紙色。影ではなく紙の縁で一段浮かせる |

## 2. 色

### 2.1 トークン（ライトテーマのみ。ダークモードは未対応で、単純な色反転をしない）

部品に色コードを直書きしない。原始値は `src/app/globals.css` の `:root` だけに置き、`tailwind.config.ts` は CSS変数を参照する。

| Tailwind名 | CSS変数 | 値 | 役割 | コントラスト |
|---|---|---|---|---|
| `surface` | `--c-paper` | #efeee9 | 台紙（ページ背景） | 墨と 14.2:1 |
| `panel` | `--c-sheet` | #ffffff | 用紙（カード・表・入力欄） | — |
| `subtle` | `--c-paper-2` | #f4f3ef | 補助面・無効状態の面・ボタンの下側の段 | — |
| `tint` | `--c-tint` | #e4ebf2 | 藍の網掛け（見出し行・現在庫欄・選択の面） | 墨と 13.7:1、朱と 5.3:1 |
| `ink` | `--c-ink` | #1d201e | 本文・数値 | 白と 16.4:1 |
| `muted` | `--c-ink-2` | #575c58 | 補助文 | 白と 6.8:1、網掛けと 5.7:1、紙と 5.9:1 |
| `line` | `--c-rule` | #d8d6cf | 装飾の罫・カードの縁。操作境界の唯一の手掛かりにしない | 1.45:1（装飾） |
| `lineStrong` | `--c-rule-strong` | #868a84 | **操作部品の枠**（入力欄・枠ボタン・選択欄） | 白と 3.5:1、紙と 3.02:1（紙の上では余裕が小さいため、入力欄は白い面の上に置く） |
| `accent` | `--c-ai` | #1f4e79 | **藍＝押せる物・刷り**（主操作、リンク、ナビ帯、見出し行の罫） | 白と 8.7:1 |
| `accentDeep` | `--c-ai-deep` | #163a5b | 藍のhover・active | 白と 11.7:1 |
| `accentEdge` | `--c-ai-edge` | #102a42 | 塗りボタンの下端の厚み | — |
| `controlEdge` | `--c-control-edge` | #a9a59b | 枠ボタンの下端の厚み | — |
| `mark` | `--c-mark` | #ffe066 | **黄のマーカー面＝注意**（小さい面だけ） | 墨と 12.6:1 |
| `markSoft` | `--c-mark-soft` | #fff4c2 | 注意の案内枠の面（広い面） | 墨と 14.9:1 |
| `danger` | `--c-shu` | #b52a1c | **朱＝停止**（在庫0・エラー） | 白と 6.3:1 |
| `success` | `--c-green` | #1e6b45 | 完了の文字とアイコン | 白と 6.5:1 |
| `focus` | `--c-focus` | #ffd400 | フォーカスの黄（墨と二重で使う） | 墨と 11.5:1、藍と 6.1:1 |

- `warning` と `caution` は廃止する。黄は文字色にしない（白地で読めない）。注意は `mark` の面＋墨の文字で示す。
- 色相は墨（無彩色）・藍・黄・朱・緑の5つ。これ以上増やさない。

### 2.2 意味の固定（色の使い方の規則）

1. **藍＝押せる・構造。** ボタン、リンク、ナビ帯、見出し行。根拠: 大手5サイトとも押せる物は濃い青、ISO 7010の指示標識は青、伝票の刷り色。
2. **黄の面＝注意。** 基準未満、確認待ち。面（マーカー）だけに使い、文字は墨。根拠: JIS安全色の黄＝注意、NHSは警告を黄の面で示す。
3. **朱＝停止。** 在庫0（出庫できない）とエラーだけ。基準未満には使わない。根拠: JIS安全色の赤＝停止・禁止、社判の朱。
4. **情報は無彩色。** 納品待ち・長期在庫・0件などは色を付けない。強調しないものを増やす。
5. **状態には必ず文字を付ける。** 「▲ 基準在庫を下回っています」「■ 在庫切れ」「✓ 記録しました」。▲は文言の頭にだけ置き、数量そのものには付けない（▲5は「マイナス5」と読まれるため）。
6. **フォーカスは黄と墨の二重リングだけ。** `outline: 2px solid ink; outline-offset: 2px; box-shadow: 0 0 0 2px focus`。色を変えない。根拠: デジタル庁・GOV.UK・NHS共通。
7. 緑と朱（1型 ΔE 9.7）、緑と藍（3型 ΔE 8.9）は色覚によって見分けにくい。緑は ✓ と完了の文言を必ず付け、色だけで区別させない。

### 2.3 状態の表し方

| 状態 | 面 | 文字 | その他 |
|---|---|---|---|
| 通常 | 白 | 墨 | — |
| 注意（基準未満・確認待ち） | `mark`（現在庫欄・件数の下半分） | 墨・太字、「▲ 」付きの文言 | — |
| 停止（在庫0） | 白（現在庫欄は `tint`） | 朱の数量と「■ 在庫切れ」 | カードの左に朱の4pxの線 |
| エラー | 白 | 朱、内容と再確認の方法 | 左に朱の4pxの線 |
| 完了 | 白 | 緑、「✓ 」付き | — |
| 無効 | `subtle` | `muted`＋押せない理由の文言 | 低い不透明度だけで済ませない |

- エラー・完了・注意の案内枠に、`bg-red-50` のような淡い色の面を使わない。区別は左の線・記号・文言で付ける。

## 3. 文字サイズ（業務階層の上端。共通UI設計ガイド §1）

利用者にITに慣れていない人を含むため、業務階層の上端を下限とする。

| トークン | 値 | Tailwind | 用途 |
|---|---:|---|---|
| `--fs-2xs` | 12px | `text-xs` | カテゴリ名、規格、単位、補助の補助。**これが下限** |
| `--fs-xs` | 13px | `text-label` | 表ヘッダー、フォームのラベル、状態表示 |
| `--fs-sm` | 14px | `text-sm` | 表セル、ボタン、補助文 |
| `--fs-md` | 16px | `text-base` | 本文、商品名、入力欄、ナビ |
| `--fs-lg` | 18px | `text-lg` | セクション見出し |
| `--fs-xl` | 22px | `text-xl`（20pxから変更） | ページ見出し（スマホ20px） |
| `--fs-2xl` | 24px | `text-2xl` | 主役の数値（カードの現在庫） |

- 11px以下と半端な値（10.5px等）、`text-3xl` 以上、`text-[Npx]` を使わない。
- 例外は商品詳細の現在庫だけ（2026-09-15の判断で48px）。`text-display` として1箇所に限る。
- 出庫・納品カードの中の文字サイズは変えない（下記 §5.4）。

## 4. 余白とページ枠

| 部分 | 値 |
|---|---|
| 上部ナビ | 1段・高さ56px。藍の帯、現在地は紙色のタブ＋太字。院名・担当者選択・「その他」を右に置く。スマホは院名が1段目、ナビ項目は横スクロール |
| 「その他」 | 管理、マニュアル、アカウント、区切り線、ログアウト。ログアウトは区切り線の下 |
| 本体の上余白 | 12px（PC・タブレットの左右24px、スマホの左右12px） |
| ページ見出し | 22px・1行。説明文は原則置かない（必要な画面だけ見出しの右に14pxで1行） |
| 見出しと本体の間 | 12px |
| セクションの間 | 16px |
| カード・表の外枠 | 角丸4px、影なし、`line` の縁＋下に1pxの紙の縁 |
| 余白の内側 | 12px（従来の20〜24pxを使わない） |

- 目標: タブレット横（1024×768）で本体の開始位置が110px前後（現行202〜275px）。
- 画面の背景にグラデーションを使わない。`shadow-panel` を使わない。

## 5. 部品

### 5.1 ボタン（押せる物は出っ張り、入力欄はへこみ）

| 種別 | 見た目 |
|---|---|
| 主操作（画面の主役の1つ。出庫カードは各カードの確定ボタン） | `bg-accent` 白文字。下端に `accentEdge` で3pxの厚み、上縁に白の薄い光 |
| 枠ボタン（＋／−、解除、商品詳細を確認 など） | 白から `subtle` への段差、`lineStrong` の枠、下端に `controlEdge` で2pxの厚み |
| 押した瞬間 | 2px沈み、内側に影 |
| 選択中（カテゴリー等） | `bg-accent` で押し込まれたまま（内側の影）＋ ✓ |
| 入力欄・選択欄 | 白、`lineStrong` の枠、内側に薄い影（へこみ） |
| リンク | 藍＋下線 |

- 厚みと影は `box-shadow` だけで付け、ボタンの寸法を変えない。高さ40px以上（主要操作48px）を維持する。
- 塗りつぶしは原則1画面に1つ。例外は出庫・納品カードの確定ボタン（各カードの主操作）。

### 5.2 見出し行・表

- セクション見出し: 16〜18px・太字・藍の文字、`tint` の面、上に2pxの藍の罫。
- 表ヘッダー: 13px・`tint` の面・藍の文字・下に藍の罫。行は `line` の罫で区切る。セルに色を塗らない（例外の行だけ §2.3）。

### 5.3 ホーム

- 出庫・納品は2つの大きなボタン（高さ88px前後）。出庫を藍の塗り、納品を白に藍の上罫。
- 「今日の注意」は罫で区切った表（4列）。件数は22px。停止＝朱、注意＝黄マーカー、情報と0件は無彩色。説明文は常時表示しない。
- 「直近の在庫更新」は表、「確認メニュー」は罫の一覧（1行48px）。タイルを使わない。

### 5.4 出庫・納品カード（寸法を変えない）

- 写真80px、内側の余白8px、要素の間隔4px、数量48px角の増減ボタン、48px高の確定ボタン、商品名16px・規格12px・現在庫24px は現行のまま。
- 変えるのは色・線・角・影だけ。上に2pxの藍の罫（`box-shadow: inset`）、現在庫欄は `tint` の面、「出し方」の項目名は藍の小札。
- 2026-10-08のモックで、1024・768・390pxの全カード行の高さが現行と1pxも違わないことを確認した。実装後も同じ計測で確認する。

## 6. 画面別の決定（出庫・納品・商品詳細。色と余白は §1〜§5 が優先）

- 既存のシステムフォントを使い、フォントの外部取得は行わない。
- 商品名16px以上、数量24px以上、入力16px以上、補助説明14pxを基本にする。規格を省略して誤認させない。
- カードは写真枠を左に置き、商品名・規格を並べる。出庫カードでは長い商品名・規格を写真の下へ回り込ませ、写真横の狭い幅だけで縦長にならないようにする。出庫・納品一覧の写真枠は80pxとし、写真なしでも商品名で判別できる。新しい商品画像の取得は対象外。
- カードは小幅1列、タブレット縦2列、1024px以上4列を基本にし、420商品でも検索・カテゴリで絞れる。最初は少数を描画し「さらに表示」で続きを表示する。
- タップ操作は48px以上を基本とする。ホバーしないと操作できない部品を作らない。
- 検索欄とカテゴリ切替はカード上部へ置く。「カテゴリー」は操作できない見出しとしてボタン群の上段へ分離し、その下で選択肢を横スクロールにせず画面幅に応じて折り返す。全件を同じ画面内に表示し、行数を固定せず、タブレット横幅では概ね2段以内を目標にする。
- 出庫カードは同じグリッド行の高さを揃え、操作部を下端へ置く。商品名・規格は省略記号で切らず、長い英数字を含めて単語途中でも自然に折り返す。
- 出庫カードの商品写真・商品名・規格を置く先頭領域は、タブレット2列では80px、4列では96px以上を確保し、その下の「出し方」「現在庫」「数量」の開始位置を同じ行のカード間で揃える。内容が長い場合は領域を伸ばして全文を表示する。「元表発注名」は発注時の照合情報として保持し、出庫・納品カードには表示しない。
- （2026-10-08に置換）通常画面右上の補助操作は §4 の「その他」へまとめる。2026-09-10の「同じ高さ・枠・背景で横に並べる」は廃止した。
- 出庫数はカード内の48px高入力へ初期値1を表示し、左右の48px角の「−」「＋」でタッチ変更できるようにする。その下の「2箱を出庫」のように数量と単位を明記したボタンを押すと即時記録する。担当者は画面上部の共通選択だけを使い、カード内や確認画面では再選択させない。
- 単位未確認品は出庫操作を表示せず、何を1と数えるか、現在庫・基準数が同単位か、開封済みの残数を現物確認する手順を展開表示する。箱→本の暗黙換算はしない。
- 空状態は「商品登録なし」と「検索結果なし」を区別し、戻り先・解除方法を示す。
