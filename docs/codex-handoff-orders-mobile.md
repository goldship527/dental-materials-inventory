### 2.2 見出し横のボタン（§99.1）

1. 新しいクライアント部品 `src/app/(app)/orders/orders-header-menu.tsx` を作る。
   - 639px以下（`sm:hidden`）だけで表示する。ボタンの文言は「関連ページ・印刷」。
   - 押すと下に一覧を開く。項目は「不足一覧へ」（`/shortage`）、「発注書下書き」（`/orders/print`）、「発注記録」（`/order-records`）、「印刷」（`window.print()`）。
   - 一覧は `absolute` で右寄せ、幅は画面内に収める（`right: 0`、`max-width: calc(100vw - 24px)`）。白い面、`line` の縁、1行48px、項目の間に `line` の罫。
   - ボタンに `aria-expanded`・`aria-controls` を付ける。Esc・外側のタップ・項目の選択で閉じ、閉じた後はボタンへフォーカスを戻す。共通ナビの「その他」と同じ作りでよい。
   - `print:hidden`。
2. 現行の4ボタンの段（`flex w-full gap-2 overflow-x-auto ...`）に `max-sm:hidden`（または `hidden sm:flex`）を付け、640px以上だけで表示する。
3. 「発行日時」の `<p>` にクラス `orders-issued-at` を付け、`globals.css` の `@media screen and (max-width: 639.98px)` で `display: none` にする。
   - `max-sm:hidden` は使わない。A4縦の印刷幅（余白12mmを除いて約627px）は640px未満なので、印刷でも隠れてしまう。
   - 印刷では現行どおり出す。印刷用の注記の `span` も現行どおり。
   - 同じ理由で、2.2-1・2.2-2の `sm:hidden`／`max-sm:hidden` は、どちらも `print:hidden` の要素だけに使う。

### 2.3 カードの操作（§99.2）

カード表示の指定は、これまでどおり `globals.css` の `@media screen and (max-width: 1023.98px)` だけに書く。Tailwindの `max-lg:` は印刷幅でも効くので使わない。

1. 「その他の操作」のパネル（`order-more-panel`）に、カード表示のときだけ見える項目を2つ足す。
   - 「発注先を変更」: `canChangeSupplier` のときだけ。押すと `togglePanel("supplier")` と同じ状態にし、発注先の段にある既存のフォームを開く。クラス `order-card-only`。
   - 「数量を変えて発注予定へ」: 確認待ちのときだけ。押すと `togglePanel("quantity")` と同じ状態にし、既存の数量フォームを開く。クラス `order-card-only`。
   - 確認待ちのパネルの並びは、「この行だけ発注予定へ」「数量を変えて発注予定へ」「発注先を変更」「見送り」の順。
2. `globals.css`:
   - `.order-card-only { display: none; }`（全幅・印刷で既定）
   - カード表示の中で `.order-card-only { display: block; }`（ボタンなら `inline-flex` でもよい。パネル内は全幅の縦並び）
   - カード表示の中で、発注先の段の「発注先を変更」ボタンを隠す。そのボタンにクラス `order-supplier-change` を付けて対象にする。フォームそのものは隠さない（開いたときに発注先の段に出る）。
   - カード表示の中で、確認待ちの `order-card-qty-action` を隠す。確認待ちのときだけクラス `order-card-qty-suggested` を付けて対象にする。
3. 発注予定・納品待ちのカードでは「数量変更」を外に残す。
   - 「数量変更」「納品確認」「その他の操作」の3つが、390px（スクロールバー15pxあり）で1行に収まることを計測で確かめる。
   - 収まらない場合は、ボタンの左右の余白を `px-3` から `px-2.5` に詰める。それでも収まらなければ止めて報告する（文言は変えない）。
4. 1024px以上の表の見た目と動作は変えない。`order-card-only` の項目が1024px以上で出ないことを確かめる。

### 6.1 確認した点（問題なし）

- 見出しメニュー:
  - `sm:hidden print:hidden`。4ボタンの段は `hidden sm:flex print:hidden`。
  - 開閉は Esc・外側タップ・項目選択で閉じ、ボタンへフォーカスを戻す。
  - 項目は48px・14px・藍の文字。
- 「発行日時」: `orders-issued-at` を `@media screen and (max-width: 639.98px)` だけで隠している。印刷では出る。
- その他の操作:
  - 確認待ちの並びは「この行だけ発注予定へ」「数量を変えて発注予定へ」「発注先を変更」「見送り」で、§99.2のとおり。
  - 追加項目は `order-card-only` で、カード表示の中でだけ見える。1024px以上の表は変わらない。
- 回帰CI・Vercel Preview成功。サーバーの変更なし。

### 6.2 修正（必須）: カード表示で、開いたフォームを閉じるボタンが無い

- 起きること:
  - カード表示では、発注先の段の「発注先を変更」（`order-supplier-change`）を隠している。このボタンは、フォームが開いている間は「閉じる」に変わるボタンでもある。
  - そのため、「その他の操作」→「発注先を変更」でフォームを開くと、閉じるボタンが画面に無い。確認待ちの「数量を変えて発注予定へ」（`order-card-qty-suggested`）も同じ。
  - 利用者は、送信するか、別の操作を開く以外にフォームを閉じられない。
- 直し方:
  1. 発注先の段の「発注先を変更」ボタンと、確認待ちの `order-card-qty-action` ボタンに `aria-expanded={activePanel === "supplier"}`／`{activePanel === "quantity"}` を付ける（数量の方は付与済み）。
  2. カード表示の中で、開いているときだけ表示する:
     - `.order-supplier-change[aria-expanded="true"] { display: inline-flex; }`
     - `.order-card-qty-suggested[aria-expanded="true"] { display: inline-flex; }`
     - ボタンの文言は既存どおり開いている間「閉じる」。
  3. 3.2の確認に「カード表示で、その他の操作から開いた発注先・数量のフォームを『閉じる』で閉じられる」を追加して確かめる。
